# Testing Guide — Somatic Variants Pipeline

## Overview

The pipeline ships with a self-contained **Python test runner** that:

1. Exercises all downstream pipeline steps (BED overlap → candidate selection → drug annotation → TMB → MAF)
2. Converts the test VCF using `benchmark_convert_pretty_to_vcf.py`
3. Computes **ROC curves**, **AUROC**, **Precision-Recall curves**, and **AUPRC** against truth labels
4. Generates **9 publication-quality PNG plots**
5. Writes a **structured HTML report** (`test_results/test_report.html`) with metrics, tables, file locations, and all plots

The test runner requires only **Python 3.8+** with `matplotlib`, `numpy`, and `scipy` — no R, Nextflow, Docker, or reference data needed.

## Quick start — run all tests

From the pipeline root directory:

```bash
python3 scripts/run_pipeline_test.py
```

This uses the bundled synthetic test data (`test_data/synthetic_pretty.csv`) and BED files automatically. Expected output:


## Custom data

```bash
python3 scripts/run_pipeline_test.py \
    --data   /path/to/your_variants_pretty.csv \
    --target /path/to/target.bed \
    --bait   /path/to/bait.bed \
    --outdir /path/to/output_dir
```

| Argument | Default | Description |
|----------|---------|-------------|
| `--data`   | `test_data/synthetic_pretty.csv` | Variants CSV (must have `truth_label` column for ROC/PR) |
| `--target` | `test_data/target.bed` | Capture target BED |
| `--bait`   | `test_data/bait.bed` | Bait/padded BED |
| `--outdir` | `test_results/` | Directory for all outputs |

---

## What is tested

| Step | What it checks | Pass criterion |
|------|---------------|----------------|
| **Load CSV** | File exists and contains valid rows | n_rows > 0 |
| **BED overlap** | Territory annotation runs without error | ≥1 variant annotated |
| **Candidate selection** | selectionOfCandidates logic runs | ≥1 variant processed |
| **Drug annotation** | ExonicFunc→mc mapping; druggable flag | Completes without error |
| **TMB** | exome_mb computed from BED; TMB per sample | ≥1 sample has TMB value |
| **MAF** | Max FREQ per subset (all/on_target/selected) | ≥1 sample has MAF value |
| **VCF conversion** | `benchmark_convert_pretty_to_vcf.py` runs | Return code = 0; VCF file created |
| **ROC/PR** | AUROC and AUPRC computed from truth labels | Curves have valid shape |

## CI integration

The Python test runner is integrated into the CI workflow (`.github/workflows/ci.yml`):

```yaml
- name: Run downstream pipeline test
  run: python3 scripts/run_pipeline_test.py --outdir /tmp/ci_test_results
```

This runs on every push and pull request, validating all downstream logic without needing Nextflow or R.

## Adding truth labels to your own data

To compute AUROC/AUPRC on your own dataset:

```bash
# 1. Convert calls to VCF with truth labels
python3 scripts/benchmark_convert_pretty_to_vcf.py \
    --input  YOUR_variants_pretty.csv \
    --output calls.vcf \
    --truth  GIAB_truth.vcf.gz \
    --sample SAMPLE_ID

# 2. Run score-based performance evaluation
# (calls benchmark_performance.R internally via BENCHMARK_VARIANTS module)
# Or run directly:
python3 scripts/run_pipeline_test.py \
    --data YOUR_variants_pretty_with_truth_labels.csv \
    --outdir my_benchmark_results
```

The input CSV must have a `truth_label` column (0 = not in truth set, 1 = in truth set).

## Troubleshooting

**Q: `ModuleNotFoundError: No module named 'matplotlib'`**
```bash
pip install matplotlib numpy scipy pandas
```

**Q: Plots are blank or empty**  
The script uses `matplotlib.use("Agg")` for headless rendering. Ensure matplotlib ≥ 3.5.

**Q: AUROC/AUPRC are not computed**  
The input CSV must have a `truth_label` column (0/1). Use `benchmark_convert_pretty_to_vcf.py` to add truth labels from a GIAB VCF.

**Q: All variants are in "off" territory**  
Check that Chr values in the CSV match the BED chromosome names (both with or both without `chr` prefix).

**Q: Test exits with code 1 but all tests pass**  
Exit code 1 is returned only if any test fails. Check the `Tests FAILED:` line in the output.
