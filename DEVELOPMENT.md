# Development Branch

This branch tracks active development of the **Somatic Variants Pipeline**.

## Merged changes

| Branch | Description |
|--------|-------------|
| `copilot/add-multiqc-reporting` | Added MultiQC QC aggregation across all pipeline stages and a Quarto-based HTML clinical report |

## How to contribute

1. Branch off `development` for new features/fixes.
2. Open a PR targeting `development`.
3. Once stabilised, `development` is merged into `main` for release.
